# Math Ver2

## 概要

Ver2 の Math カテゴリは、補間・除算・加算木などの共通演算ブロックを提供します。

## 実装配置

- `rtl/v2/math`

## 代表モジュール

- `jelly2_sum_tree.sv`
  - 複数入力を木構造で加算するモジュールです。集計演算やフィルタ演算に利用できます。
- `jelly2_integer_divider.sv`
  - 整数除算を行うモジュールです。
- `jelly2_linear_interpolation.sv`
  - 線形補間を行うモジュールです。
- `jelly2_bilinear_interpolation.sv`
  - 2 次元のバイリニア補間を行うモジュールです。

## 利用方針

- 本章は代表モジュールのみを記載し、補助ユニットや内部構成モジュールは省略します。
- 目的の演算に合わせて演算精度とレイテンシを調整する運用を推奨します。
