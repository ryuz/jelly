# Math Ver3

## 概要

Ver3 の Math カテゴリは、加算木・最大値選択木・疑似乱数生成などの共通演算ブロックを提供します。

## 実装配置

- `rtl/v3/math`

## 代表モジュール

- `jelly3_sum_tree.sv`
  - 複数入力を木構造で加算するモジュールです。畳み込みや集計処理の部分和計算に利用できます。
- `jelly3_max_tree.sv`
  - 複数入力の最大値を木構造で選択するモジュールです。Pool 系処理や比較器削減に利用できます。
- `jelly3_lfsr.sv`
  - 線形帰還シフトレジスタによる疑似乱数生成モジュールです。テストパターンや初期値分散に利用できます。

## 利用方針

- サブモジュールは内部実装として扱い、本章ではトップレベルの代表モジュールのみ記載します。
- 演算段数はタイミングと資源のトレードオフになるため、用途に応じてパラメータ調整する運用を推奨します。
