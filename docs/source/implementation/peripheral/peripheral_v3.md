# Peripheral Ver3

## 概要

Ver3 の Peripheral カテゴリは、SoC で利用頻度の高い汎用周辺 I/O を提供します。

## 実装配置

- `rtl/v3/peripheral`

## 代表モジュール

- `jelly3_gpio.sv`
  - 汎用デジタル I/O 制御モジュールです。
- `jelly3_uart.sv`
  - シリアル通信用 UART モジュールです。
- `jelly3_i2c.sv`
  - I2C バス制御モジュールです。
- `jelly3_system_control.sv`
  - システム制御用のレジスタ群や管理機能をまとめるモジュールです。

## 利用方針

- サブモジュールは記載対象外とし、システム統合時に直接選定しやすいトップモジュールを中心に整理します。
- ボード依存のピン制約やクロック条件は各プロジェクト側で定義する前提です。
