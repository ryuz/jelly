# RTOS Ver2

## 概要

Ver2 の RTOS カテゴリは、ハードウェア実装のリアルタイム OS 機能を提供します。

## 実装配置

- `rtl/v2/rtos`

## 代表モジュール

- `jelly2_rtos.sv`
  - RTOS サブシステム全体のトップモジュールです。
- `jelly2_rtos_core.sv`
  - スケジューリングと制御の中核モジュールです。
- `jelly2_rtos_task.sv`
  - タスク管理を行うモジュールです。
- `jelly2_rtos_queue.sv`
  - メッセージキュー機能を提供するモジュールです。
- `jelly2_rtos_semaphore.sv`
  - セマフォ同期を提供するモジュールです。
- `jelly2_rtos_timer.sv`
  - タイマ管理を行うモジュールです。

## 利用方針

- 本章は代表モジュールのみを記載し、優先度キューや FIFO などの下位実装モジュールは省略します。
- RTOS 機能は割り込み設計と密接に関係するため、SoC 全体のイベント設計と合わせて統合する運用を推奨します。
