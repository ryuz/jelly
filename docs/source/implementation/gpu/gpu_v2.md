# GPU Ver2

## 概要

Ver2 の GPU カテゴリは、テクスチャ参照とキャッシュ制御を中心とした描画補助ブロックを提供します。

## 実装配置

- `rtl/v2/gpu`

## 代表モジュール

- `jelly2_texture_sampler_2d.sv`
  - 2 次元テクスチャサンプリングを行うモジュールです。
- `jelly2_texture_cache_l1.sv`
  - テクスチャ参照の一次キャッシュを構成するモジュールです。
- `jelly2_texture_cache_l2.sv`
  - テクスチャ参照の二次キャッシュを構成するモジュールです。
- `jelly2_texture_cache_dma.sv`
  - 外部メモリとのデータ搬送を行う DMA 連携キャッシュモジュールです。
- `jelly2_texture_writer_core.sv`
  - テクスチャ書き込み側の中核モジュールです。

## 利用方針

- 本章は代表モジュールのみを対象とし、タグ管理や補助ユニットなどのサブモジュールは省略します。
- 画像サイズとアクセス局所性に応じて、L1/L2 キャッシュ構成を使い分けることを推奨します。
