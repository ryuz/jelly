# Library v2

## 概要

v2 は `jelly2_` 系の共通ライブラリ群です。

## 実装配置

- `rtl/v2/library`

## 主要モジュール

- `jelly2_fifo_async.sv`
- `jelly2_fifo_fwtf.sv`
- `jelly2_ram_simple_dualport.sv`
- `jelly2_ram_with_autoclear.sv`
- `jelly2_stream_width_convert.sv`
- `jelly2_address_generator_nd.sv`
- `jelly2_capacity_buffer.sv`
- `jelly2_signal_transfer_async.sv`

## 利用指針

- v2 世代の各機能コアは library 依存が強いため、版混在より同世代統一を推奨します。
- v3 へ移行する場合は、まず stream/fifo 系から置換すると影響を限定できます。
