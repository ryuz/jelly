# Primitive Ver3

## 概要

Ver3 の Primitive カテゴリは、CDC、基本順序回路、合成時に有用な低レベル部品を提供します。

## 実装配置

- `rtl/v3/primitive`

## 代表モジュール

- `jelly3_cdc_single.sv`
  - 単一ビット信号のクロックドメイン間同期モジュールです。
- `jelly3_cdc_handshake.sv`
  - ハンドシェーク付き CDC モジュールです。確実なイベント受け渡しに利用できます。
- `jelly3_cdc_pulse.sv`
  - パルス信号のドメイン越えに特化した CDC モジュールです。
- `jelly3_shift_register.sv`
  - 汎用シフトレジスタです。遅延線や整列用途に利用できます。
- `jelly3_flipflops.sv`
  - 基本フリップフロップ列をまとめたモジュールです。

## 利用方針

- 本章は代表プリミティブのみを対象とし、バリエーションや内部補助部品は省略します。
- CDC まわりはシステム全体の同期設計と合わせて利用条件を確認することを推奨します。
